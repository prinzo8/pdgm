# PDGM - Pharmacie du Grand Marché

Website for Pharmacie du Grand Marché in San Pedro, Côte d'Ivoire.

## Features
- Pharmacy information
- Opening hours
- Contact information
- Pharmacy duty status
- Live medication availability search
- Alphabetical medication search
- Available / unavailable status
- Responsive design

## Technology
- WordPress
- PHP
- MySQL
- Docker
- HTML / CSS / JavaScript

## Development
```bash
docker compose up -d
```

## Theme
The custom theme is located in `wordpress/wp-content/themes/pdgm/`.

## Deployment
The WordPress version requires PHP and MySQL. A separate static version will be prepared for Netlify.
